# Settings Validation

## Overview

This project focuses on implementing and improving form validation for a settings interface as part of my Frontend Development Internship at FlyRank AI.

The work includes implementing a settings component, handling user input, and comparing different approaches to prompt-driven implementation and validation.

---

## Files

### `Setting.jsx`

Contains the implementation of the settings interface and related frontend logic.

### `SettingFormValidation.html`

Contains the HTML implementation focused on form validation.

### `WORKFLOW.md`

Documents the workflow and implementation process followed during the task.
